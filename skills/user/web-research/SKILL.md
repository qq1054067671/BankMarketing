# Web Research Skill（Weather）

## 适用场景
- 用户问“某地现在天气如何/适合穿什么/要不要带伞”。
- 用户给中文城市名、英文城市名或中英混合名称。

## 领域知识（Weather）
- 查询顺序必须是：**城市标准化 → 地理编码 → 当前天气查询 → 天气码解读 → 建议输出**。
- 天气数据来源：Open-Meteo（无需 API Key）。
- 输出应至少包含：温度、体感温度、湿度、风速、天气现象。

## 标准工作流
1. 识别城市名：若用户没给城市，先追问城市。
2. 调 `city_to_coordinates` 获取标准化地理位置与经纬度。
3. 调 `weather_by_coordinates` 获取实时天气并完成天气码解读。
4. 结合温度、风速和湿度输出简洁建议（穿衣/出行）。

## 失败处理
- 城市未匹配：返回“未找到城市”并建议用户补充国家或省份。
- 上游 API 异常：明确提示暂时不可用，建议稍后重试。

## 实现约定
- 模型可调用能力放在同目录 `tools.py`（使用 `@tool` 注解）。
- 工具实现直接写在 `tools.py`，不从 `helper.py` 引入。
